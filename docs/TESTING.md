# შემოწმება

გაუშვით `npm test`, `npm run typecheck` და `npm run build`.

ტესტები მოიცავს ფასებს, ფასდაკლებას, შერეულ გადახდებს, განმეორებითი მოთხოვნების დაცვას, ვერსიების შეჯახებას, მენეჯერის PIN-ს, სწრაფ დაჭერებს, სესიას, მომხმარებელთა იზოლაციასა და Supabase HTTP კონტრაქტებს.

Supabase ქსელური პასუხები ტესტებში ჩანაცვლებულია. რეალურ ბაზაზე სქემის, ნებართვებისა და ავტორიზაციის შემოწმება საჭიროა დაკავშირების შემდეგ. ამ ეტაპზე Next.js-ის build და TypeScript შემოწმება გავლილია; ბრაუზერით ვიზუალური და რეალურ სერვისებზე სრული შემოწმება არ ჩატარებულა.

ცოცხალი შემოწმების ნაბიჯები იხილეთ [განთავსების გზამკვლევში](VERCEL.md).
