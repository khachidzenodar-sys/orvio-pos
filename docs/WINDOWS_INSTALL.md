# ORVIO Windows-ზე — დაყენება და განახლება

ეს ინსტრუქცია მფლობელისთვისაა. პროგრამირების ცოდნა არ სჭირდება.

ORVIO-ს Windows აპი მუშაობს **ინტერნეტის გარეშე**. ყველა მონაცემი ინახება თქვენს კომპიუტერზე. შესვლის ეკრანი არ არის: აპი პირდაპირ მაგიდების ეკრანით იხსნება.

## 1. ინსტალერის ჩამოტვირთვა GitHub-იდან

ინსტალერს GitHub ავტომატურად აწყობს (სერვისი „GitHub Actions“).

1. გახსენით რეპოზიტორია GitHub-ზე და ზედა მენიუში დააჭირეთ **Actions**.
2. მარცხნივ აირჩიეთ **Windows installer**.
3. გახსენით ბოლო **მწვანე** (✓) გაშვება.
4. გვერდის ბოლოში, განყოფილებაში **Artifacts**, დააჭირეთ **orvio-windows-installer**. ჩამოიტვირთება zip ფაილი.
5. zip ფაილზე მარჯვენა ღილაკი → **Extract All…** (ამოარქივება).

შიგნით ორი ფაილია, ორივე ერთსა და იმავე აპს აყენებს:

| ფაილი | როდის გამოიყენოთ |
| --- | --- |
| `ORVIO_…_x64-setup.exe` | **რეკომენდებულია.** ჩვეულებრივი დაყენება და განახლება |
| `ORVIO_…_x64_en-US.msi` | თუ IT ადმინისტრატორი MSI-ს ითხოვს |

## 2. დაყენება

1. ორჯერ დააწკაპუნეთ `.exe` ფაილზე.
2. შეიძლება გამოჩნდეს ლურჯი ფანჯარა **„Windows protected your PC“** (SmartScreen). ეს იმიტომ ხდება, რომ ინსტალერი ციფრული ხელმოწერის გარეშეა. დააჭირეთ **More info** → **Run anyway**.
3. მიჰყევით ინსტალერის ნაბიჯებს.
4. თუ კომპიუტერს WebView2 აკლია (Windows 10/11-ზე ჩვეულებრივ უკვე არის), ინსტალერი მას თავად ჩამოტვირთავს — ამ ერთხელ ინტერნეტი საჭიროა.

დაყენების შემდეგ **ORVIO**-ს მალსახმობი ჩნდება Start მენიუში და სამუშაო მაგიდაზე (Desktop).

## 3. პირველი გაშვება

- აპი იხსნება **მაგიდების** ეკრანით, საცდელი მენიუთი და მაგიდებით.
- მენეჯერის კოდი (PIN) თავიდან არის **1234**. შეცვალეთ ის **მართვის** განყოფილებაში.
- თუ PIN-ს 5-ჯერ არასწორად შეიყვანთ, მცდელობები დროებით იბლოკება.

## 4. სად ინახება მონაცემები

```
C:\Users\<მომხმარებელი>\AppData\Roaming\ge.orvio.pos\
```

| ფაილი | შიგთავსი |
| --- | --- |
| `orvio.demo.v1.json` | მენიუ, მაგიდები, შეკვეთები, გადახდები, ჩეკები, PIN |
| `orvio.printer.v1.json` | არჩეული პრინტერი |
| `orvio.before-restore.<თარიღი>.json` | ავტომატური ასლი, რომელიც აღდგენამდე იქმნება |

ამ ფაილებს ხელით ნუ შეცვლით. მონაცემების გადასატანად გამოიყენეთ სარეზერვო ასლი (ნაწილი 6).

## 5. პრინტერის არჩევა

1. Windows-ში დააყენეთ თერმული პრინტერის (80 მმ) დრაივერი.
2. ORVIO-ში გადადით **მართვა → პრინტერი**, აირჩიეთ პრინტერი სიიდან და დააჭირეთ **„საცდელი ბეჭდვა“**.
3. სანამ პრინტერი არჩეული არ არის, ORVIO ჩვეულებრივ ბეჭდვის ფანჯარას ხსნის.

დეტალები და პრობლემების გადაჭრა: [PRINTING.md](PRINTING.md).

## 6. სარეზერვო ასლი — რეკომენდაციები

- **მართვა → „სარეზერვო ასლის შენახვა“** ქმნის ერთ ფაილს, მაგალითად `orvio-backup-2026-10-18.json`.
- გააკეთეთ ასლი **ყოველდღე** სამუშაო დღის ბოლოს და შეინახეთ **სხვა ადგილას** — ფლეშკაზე ან ღრუბლოვან საქაღალდეში (Google Drive, OneDrive). კომპიუტერის გაფუჭებისას მხოლოდ ასეთი ასლი გადაარჩენს მონაცემებს.
- რამდენიმე ბოლო დღის ასლი შეინახეთ, მხოლოდ ბოლო ერთი არა.
- **„აღდგენა ფაილიდან“** ჯერ ამოწმებს ფაილს და აჩვენებს თარიღს, შეკვეთებისა და პროდუქტების რაოდენობას. აღდგენას მენეჯერის PIN სჭირდება. აღდგენამდე მიმდინარე მონაცემების ასლი ავტომატურად ინახება, ამიტომ არაფერი იკარგება ჩუმად.
- ახალ კომპიუტერზე გადასვლა: ძველზე შეინახეთ ასლი → ახალზე დააყენეთ ORVIO → „აღდგენა ფაილიდან“.

## 7. განახლება

1. ჩამოტვირთეთ ახალი ინსტალერი (ნაწილი 1).
2. **განახლებამდე შეინახეთ სარეზერვო ასლი** (სიფრთხილისთვის).
3. გაუშვით ახალი `.exe` და დააყენეთ ძველის თავზე. წაშლა საჭირო არ არის.

მონაცემები AppData-ში რჩება და განახლებისას არ იშლება. განახლებისთვის გამოიყენეთ `.exe`: `.msi`-ს შეიძლება ერთი და იმავე ვერსიის ხელახლა დაყენებაზე უარი თქვას.

## 8. ინსტალერის ხელით აწყობა (Run workflow)

ინსტალერი ავტომატურად იწყობა ყოველ ახალ ცვლილებაზე ტოტში `claude/exciting-curie-9lz8ms`. ხელით გასაშვებად:

1. GitHub → **Actions** → **Windows installer**.
2. მარჯვნივ დააჭირეთ **Run workflow** → აირჩიეთ ტოტი → მწვანე **Run workflow**.
3. დაახლოებით 10–20 წუთში გაშვება მწვანე გახდება და **Artifacts**-ში ახალი ინსტალერი გამოჩნდება.

თუ გაშვება წითელია (✗), გახსენით ის და გადაუგზავნეთ ბმული დეველოპერს.

## 9. აპის წაშლა

Windows **Settings → Apps → Installed apps → ORVIO → Uninstall**. მონაცემების საქაღალდე (`AppData\Roaming\ge.orvio.pos`) ჩვეულებრივ რჩება — თუ მონაცემებიც აღარ გჭირდებათ, ჯერ შეინახეთ ასლი და შემდეგ საქაღალდე ხელით წაშალეთ.
